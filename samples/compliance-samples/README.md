# Project-1_Assignment

This is a project assignment from the African Leadership University

Each program corresponds to the following questions:

1. Write a simple C program that performs a calculation and prints formatted output Then explain: 	
- One read-world application of C Programming.
- The difference between syntax errors and semantic errors
- The stages of the C compilation process and the output of each stage
  
2. Develop a menu-driven C program that:
- Uses appropriate data types and variables
- Uses conditional statements (if or switch)
- Uses at least one loop
- Uses break and continue
- Allows repeated execution until the user exists
  
3. Create a C program that:
- Is broken into multiple functions
- Includes once recursive function
- Demonstrates function reuse
- Explains the advantages and limitations of recursion
  
5. Design an embedded system application that includes:
- One sensor
- One controller
- One actuator
- Explain how data flows through the system and provide a C/arduino-style program.
  
7. Briefly explain how control flow, functions, and embedded systems concepts work together in building a real-world system
